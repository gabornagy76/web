Bevezetés a HTML világába

A HTML (Hypertext Markup Language), a weboldalak szerkezetének leírására szolgáló jelölőnyelv. Nem programozási nyelv, nem futtat algoritmusokat, nem végez számításokaat, hanem megjelöli az oldal tartalmi elemeit.

A HTML a weboldal váza, a CSS a megjelnítésért felel.

HTML attributumok

A HTML elemekhez gyakran rendelünk attribútumokat. Ezek kiegészítő információt adnak az elemhez, mindig a nyitó tag-ben írjuk őket.

Például egy linknél a href attribútum értéke egy hivatkozás.

Az id és a class szerepe

Az id és a class a leggyakrabban használt szelektrok, arra szolgálnak, hogy egy HTML elemet meg tudjunk jelölni.

Id - egyedi azonosító

Az egyedi azonosítót egy oldalon csak egyszer használjuk. Akkor hasznos, ha egy konkrét, egyedi elemre akarunk hivatkozni.

Ennek a szakasznak az egyedi azonosítója a szelektorok. Ezért a navigációból a href="#szelektorok" hivatkozással tudunk ide ugrani.

Class - újrahasználható csoportosító azonosító

A class nem egyedi, több HTML elem is kaphatja ugyanazt a a class értéket.

CSS alapok

A CSS a HTM elemek megjelenését szabályozza. CSS-el állíthatnunk például színeket, betűtípusokat, margót, belső margót, szegélyeket, méreteket és szabályozhatjuk az elemek egymáshoz képesti elrendezését.

Elemkijelölők

Ha CSS-ben egyszerűen a HTML tag nevét írjuk, akkor az az összes ilyen jelölővel rendelkező elemre vonatkozni fog.

p - az összes bekezdésre vonatkozik.
h2 - az összes kettes szintű címsorra vonatkozik.

Class kijelölő

CSS-ben ha ponttal kezdünk egy kijelölőnevet, .pelda-doboz, akkor az összes olyan elemet kijelöljük, amelynek class="pelda-doboz" attribútuma van.

ID kijelölő

CSS-ben ha kettőskereszttel kezdünk egy kijelölőnevet, #css-alapok, akkor azt az egyetlen elemet jelöljük, amelynek id="css-alapok" attribútuma van.

Leszármazott kijelölő

A .fo-menu a kijelölő azt jelenti, hogy azokat a linkeket (a) formázzuk, amelyek a class="fo-menu" attribútummal ellátott elem belsejében találhatóak.

CSS dobozmodell

A CSS Box Model a webdesign egyik alapvető koncepciója. lényege, hogy a böngésző minden egyes HTML elemet egy négyszögletes dobozként kezel.
Ezen dobozok tulajdonságai határozzák meg az elemek méretét és a köztük lévő távolságokat is.

  • A content maga a tartalom, szöveg vagy kép, a tényleges tartalom. A méretét a width és height tulajdonságokka lehet szabályzoni.
  • A padding a tartalom és a szegély közötti belső térköz. Növeli a doboz belső terét.
  • A border az elem szegélye. A belső tartalmat és a belső térközt veszi körbe. Lehet neki színt, vastagságot és stílust adni. Ez a doboz látható széle.
  • A margin az elem külső margója, vagyis a többi elemtől való távolsága. A külső margó nem része a doboz kattintható felületének.

    • Alapesetben a doboz méretét a szélessége (pl. 300px), belső margója (pl. 20px) és szegélye (pl. 2px) határozza meg. Ha ezek közül bármelyik változik a működés vagy fejlesztés során, akkor a teljes dobozméret (300+20+20+2+2=344) is változik. A border-box: box-sizing; beállítás megváltoztatja ezt a működést. Ha 300px a doboz szélessége, akkor az ennyi marad akkor is, ha belső margót és szegélyt is adunk hozzá. Ebben az esetben a szegély és belső margó befelé fog növekedni.

Címsorok

A HTML-ben hat címsor van előre definiálva. h1 - h6 A h1 a legfontosabb, a h6 a legkevésbé fontos címsor.

Egy oldalon általában egy fő h1 címsort használunk. Az alfejezetekhez pedig értelemszerűen kiosztjuk a megfelelő címsorokat.

Szövegek és bekezdések

Az egyszerű bekezdéseket html-ben a p elemmel látjuk el.

Ez egy új bekezdés, automatikusan új sorba tördel és az alapértelmezett bekezdéstávolságokkal lesz ellátva.
A bekezdésen belüli sortörést a br HTML elemmel tudjuk elvégezni.

A strong elem kiemelt, fontosabb szöveget jelöl. A böngésző általában félkövér stílusban jeleníti meg.
Az em elem hansúlyos szöveget jelöl. A böngésző általában dőlt stílusban jeleníti meg.
Az mark elem kiemelt szöveget jelöl.
Alsó index jelölése a sub elemmel: H2O
Felső index jelölése a sup elemmel: a2+b2=c2

Ez egy hosszabb idézet, amelyet a blockquote elem jelöl.
Rövid idézetekhez a q elemet használjuk.
A HTML rövidítés fölé vitt egérmutató megmutatja a teljes jelentést.

Képek

Képet az img elemmel szúrunk be. Fontos attributumai:

  • src - a kép elérési útja
  • alt - a kép szöveges leírása
  • title - lebegő tooltip
  • width - a kép szélessége
  • height - a kép magassága

Példaképeket lorem picsum oldalról tudunk linkelni.
src="https://picsum.photos/300/400"
